# READ ME

This coral reef model simulates coral growth over a ten-year period using a simple dice-roll system. Under the model parameters, there are 36 possible outcomes for each coral every two years, leading to either coral growth, stagnation, or death. Over time, coral growth is determined by random chance and environmental crises, such as sea star wrecks, cyclones, and marine heatwaves.
